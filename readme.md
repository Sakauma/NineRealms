# 九境 · Nine Realms

数独游戏，包含动态主题、禅模式、彩蛋和历史回放，支持网页与 Electron 桌面版

## 构建

```bash
npm run build          # 离线网页
npm run package:setup  # Windows 安装包
```

## 检查

需要 Node.js 22.12+、Python 3 和 Chromium。DOM 测试使用锁定的开发依赖，首次在干净环境中运行：

```bash
npm ci --ignore-scripts
npm test
npm run test:dom
npm run test:improvements:browser
npm run test:browser
```

浏览器路径可通过 `CHROMIUM_PATH` 设置。DOM 模拟不替代浏览器渲染检查；CI 同时执行两类检查。依赖仅用于测试，离线网页仍无需安装依赖。

无法读取的当前存档会暂停覆盖，可导出原始数据或保留副本后开新局。副本可在页脚“原档副本”中导出，不属于“数据备份”导入格式。

经典生成题按完整的有限逻辑路径校准：入门只用单格唯一候选，标准需要区域唯一位置，进阶需要锁定候选或数对。校准受尝试次数和 Worker 超时限制，失败会明确回退题库原分档；每日、旅程、极境与旧题库保持原题。其他玩法仍按密度分档，不代表精确的人类解题难度。规则窗口中的示例按需展开。

同一来源的多个窗口优先使用浏览器写入锁，仅一个窗口保存；其他窗口可导出本窗口备份、关闭原窗口后重新读取，或仅本次游玩。临时游玩不写入当前存档、历史、收藏或探索记录。浏览器不提供写入锁时使用原文变更检查，旧版本或其他程序不遵守锁时会暂停本窗口写入，不会自动合并双方进度。

保存被拒绝时，页脚和暂停说明持续标出尚未保存；禅模式使用现有提示保留警告，成功保存后消除。未保存或临时对局可通过现有页脚入口单独导出对局原文；它不含其他记录，不作为完整备份导入。当前存档和原档副本同时无法解析时，可分别导出原文，也可保留原数据仅本次游玩。

关闭即时纠错时，新填数不核对单次答案、不累加新的答案失误，进度按已填格数显示，反馈保持中性；已有失误和历史记录不清零。仍可主动点击检查，完成整盘时仍校验完成条件。温度计的读屏说明包含球端位置和原始路径顺序，不改变可见标记。
