# 新增七种标记玩法布局

实现：`src/diversity-clues.js`。接口不变：`build({mode, solution, seed})` 返回规范化 clues；`supportedModes()`、`layoutDiversity(mode)`、`workerSource()` 继续可用。现在布局模块支持 22 种玩法。这里只构造标记，不负责挖空、难度评级或唯一解证明。

所有新布局只读取传入的合法经典完整解与种子，不读取旧题库。所有线段均正交相邻、没有重复格、没有线条之间共享格、没有自身回绕接触。短线数量有界，避免以大量线条堆叠冒充丰富内容。

| 模式 | 构造与限制 |
|---|---|
| 回文 palindrome | 2–4 条三格 A–B–A 折线。相同端点数字必须位于不同宫；没有跨远处单元格的跳线。 |
| 两端之间 between | 2–4 条 3–5 格线，内部数字严格位于两端之间，两端差至少 2。 |
| 锁定线 lockout | 2–4 条 3–5 格线，两端差至少 4，内部数字严格位于端点区间之外。 |
| 熵线 entropic | 2–4 条 3–5 格线，每个连续三格分别来自 1–3、4–6、7–9。 |
| 模三线 modular | 2–4 条 3–5 格线，每个连续三格模 3 余数不同。 |
| 宫和线 region-sum | 2–3 条 4–6 格线，恰好穿过两个不同宫；每宫连续段 2–3 格、段和相等，不重新进入先前宫。没有单宫线、完整宫 45 或一格等值段。 |
| 克隆 clone | 2–3 对两格多米诺；每个形状正交连通，两半不重叠、不相接，保持相同平移与朝向，逐位置数字相同。不使用数字重映射假造克隆。 |

## 边界与失败

路径搜索深度最多 6；在有限棋盘上枚举有限长度简单路径，没有无界随机重试。克隆只枚举有限相邻多米诺及匹配对。无法找到至少两条互不重叠线或两组克隆时，抛出带 `DIVERSITY_LAYOUT_UNAVAILABLE` 的错误，由调用方决定有界重试或明确回退。不会偷偷取旧题，也不会放宽规则或自动增加拥挤线条。

每个返回值都经过 `Engine.normalizeClues` 和对应完整解的 `Engine.validateComplete`。局部构造测试还独立重算规则，并验证这些标记能排除其他经典合法解；这不代表挖空后每条标记都必需，也不代表题目唯一或人类难度已准确评级。正式生成流程仍应承担唯一解、基础推理路径和规则实际贡献检查。

## 实测审计

运行 `node tests/diversity-marked-clues.test.cjs`，结果写入 `evidence/diversity/marked-clue-audit.json`。

本轮以从空棋盘 MRV 搜索产生的 100 个真正新经典完整解为输入，每模式构造 100 个布局，共 700 次：七种均 100 成功，0 次质量拒绝。各模式的 100 个布局在旋转、镜像（D4）归一化且忽略提示数值后，均得到 100 个不同几何类。

另固定一个完整解、仅变化 100 个种子：回文得到 81 个 D4 几何类，其余六种各 100 个。这是样本数据，不是无限新题或布局永不重复的保证；尤其短回文的可用几何空间比其他模式更小，应继续使用近期布局排重和有界拒绝。

旧 15 模式回归由 `tests/diversity-clues.test.cjs` 单独保留，新增测试同时验证 Worker 序列化与主线程一致。本审计不是浏览器截图、像素可读性、唯一题面或难度认证。
