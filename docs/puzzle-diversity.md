# 底盘与规则布局去重边界

`src/puzzle-diversity.js` 不依赖 Engine，可直接用于 Node、浏览器与生成 worker。

## API

- `equivalentSolutions(a, b)`：完整解盘是否能经数字任意重映射、三个宫带/宫栈交换、各宫带内行交换、各宫栈内列交换及转置互相变换。输入为 81 个 1–9 的数组或 81 位字符串。先用不变量快速排异，再精确搜索；**不把不变量相等当作同底盘**。
- `solutionInvariant(a)`：行对与列对置换的循环长度多重集。不同即可排除等价，相同仍必须精确判断；不是唯一签名或 hash。
- `solutionSignature(a)`：上述完整群下的规范代表，返回带版本前缀的完整 81 位串，无 hash 碰撞。它枚举两个方向 × 1,296 列置换 × 9 个首行，首行确定数字规范化，再排序每带的三行和三个带。适合审计，不宜每次 UI 渲染调用。
- `layoutSignature(mode, normalizedClues, {includeValues:false})`：仅在正方形的四次旋转和四次镜像（D4）下规范化规则的类型、位置和几何结构。默认忽略笼和、XV 值、外围和数和四格提示的数字；`includeValues:true` 保留这些数值。温度计方向、箭头圆圈端、不等号方向和规则类型始终保留。不保证任意规则图同构等价。
- `workerSource()`：返回自包含 `var NineRealmsDiversity = ...` 脚本，可在 worker 内调用同一实现。

输入解盘必须每行每列均含 1–9；也允许不遵守标准九宫的拼图解盘，但等价群仍是固定标准九宫的行列分组群，不表示任意拼图分区重编号或约束同构。模组只回答解盘结构是否同类，不证明对应题面合法、唯一可解或变体规则等价；这些检查仍由规则引擎执行。

## 在线预算

建议每个新盘最多对最近 64 个完整解盘调用 `equivalentSolutions`，有匹配即停止；不在每次填数时调用。测试机诊断值约为 64 个不同盘排异 9 ms、12 个随机对称同盘精确匹配 12 ms；机器负载可改变数值。规范签名单盘约 40–140 ms。生成的整体重试/取消预算仍由调用方负责。

去重识别本身不写入存储，不变更任何历史盘、关卡 ID 或成绩。调用方需要保存完整解盘或版本明确的规范签名，不能只保存快速不变量。

## 验证

`node tests/puzzle-diversity.test.cjs` 使用独立的随机 MRV 解盘器和独立随机群变换生成数据，覆盖随机同类、不同类、强对称盘、D4 旋转与镜像、规则数值分离、输入拒绝及 worker 一致性。时间是诊断报告，不是对低配置设备帧率的保证。
