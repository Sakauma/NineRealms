NineRealms 新题多样性第二轮交付

本包保留此前主线早期变体、精选、练习衔接、音效/BGM与已确认UI。没有提交、推送或修改版本号；源码与单文件HTML均在包内。

核心变化
1. 真正新底盘从22扩至32种玩法，新增不规则宫、多盘与7种线/标记规则。
2. 普通新游戏不再在构造失败时悄悄回退旧题，保留当前棋局；存档失败也拒绝替换。
3. 变体从挖空数量标档改为规则推演层级，逐题确认完整推演和目标层级；仍不等于完整人类技巧评级。
4. 已完成主线章节与精选入口提供同规则新题独立练习，不改旧关卡、星级或教学题本身。
5. 2026-11-15起每日采用冻结的日期新构造策略，8类轮换；旧日期、旧存档身份兼容。每日构造失败仍有明确标识的固定后备，不算新题。

独立审计
32玩法×30请求：957成功、3明确拒绝。全部成功题完整规则、唯一解、评级及路径复验通过；957底盘归一签名互异，23种有布局模式的成功题D4布局互异。中位73ms、95分位342ms、最长2164ms，当前宿主无超过8秒样本。完整题与拒绝信息在docs/diversity-audit/v4-audit-30.json。多盘采用保守子盘谱，不冒称完整多盘图同构认证。

限制
奇迹规则穷举只有72个合法终盘，经典等价群归并1类，不能承诺无限独立底盘。近期排重缓存256项并非永久去重。固定主线和精选仍固定；新增独立练习解决重复游玩，不破坏旧进度。规则推演层级未由真人难度实验标定。未完成真实Windows/手机像素、音频和原生包验收；DOM/Worker及低预算模拟不得当作实机性能保证。

运行
直接打开根目录 nine realms.html，或使用原有构建/桌面打包流程。
源码校验：npm test；npm run test:dom；npm run build 后 npm run verify。
本包不含 node_modules/.git；若需要测试先按package-lock安装依赖。
