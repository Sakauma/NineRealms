# 新底盘、规则推演与固定内容续玩（v4）

## 覆盖
普通与禅模式的新游戏支持32种玩法从空盘构造终盘，不读取旧答案后只换数字或重挖空。除上一版22种外，新增不规则宫、双盘、武士五盘、回文、两端之间、锁定线、熵线、模三线、宫和线和克隆。22种标记玩法会另造布局。不规则宫会生成连通且各含9格的区域，再为该区域独立求新解。

唯一例外是奇迹模式。穷举得到72个合法终盘，经典数独等价群归并为1类；不能诚实承诺这种规则下有无限不同结构。它保留原路径，见 `miracle-space.txt`。

## 质量与难度
每次挖空须满足完整规则、唯一解、未耗尽搜索预算。经典等已支持技巧评级的模式严格匹配原技巧等级。其他模式不再仅按挖空数量标档，而是从题面开始，利用完整规则候选计算和显性/隐性单数同步推演，按需要的推演轮数匹配入门、标准、进阶。具体阈值及证据见 `rule-path-grading.md`。给定数仍有上下界以避免空档和过满题面。

这叫“规则推演层级”，不等于完整的人类技巧难度，更不是趣味性认证。推演没有利用答案，也不作猜测；达不到要求则明确拒绝，不改标签蒙混过关。各条规则不保证都为唯一解所必需。

普通新游戏失败、取消、超时或保存失败均保留原局，不再静默换成旧题。Worker仍有8秒看门狗；同步基准成功不等于慢设备上一定能在8秒内交付。

## 排重范围
单盘终盘以完整经典数独对称群归一：数字重映射、行列在带栈内交换、带栈交换、转置不算新结构。多盘采用各子盘的经典归一签名排序组成保守谱，拒绝只变换各子盘的情况；不是完整多盘图同构证明。规则几何另按旋转/镜像D4去重，不规则宫还消除区域标签重命名。

沿用256项近期签名缓存，每局最多占题面/底盘/布局3项，至少覆盖约85局，不是无限历史保证。缓存保持备份兼容。

## 主线、精选和每日
旧主线编号、16道教学精选、通关星级和历史不改。完成章节和精选/规则入口可启动“同规则新题·独立练习”，确实走新生成，不把练习冒充重复通关，也不会覆盖主线成绩。

2026-11-15起每日v3采用冻结生成策略，8日轮换：经典、温度计、对角线、杀手笼、窗口、箭头、骑士、温笼。日期决定题目，普通生成器未来变化不会重排这些日期。过去v1/v2日期、已保存的旧未来日期身份继续识别。固定预算失败使用同模式明确标注的固定后备题，不称新生成题。详见 `daily-construction-v3.md`。每日入门题采用确定性的基础推演可完成检查，不声称与普通v4分级相同。

启动默认题、极境、奇迹和每日明确后备仍可能来自旧库。

## 验证
- `npm run test:diversity`：新源/布局、等价变换、完整规则唯一解、分级、旧v3合同、每日冻结与故障预算。
- `npm run test:dom`：真实Worker源码在DOM环境下的取消/失败/保存恢复/独立练习/每日历史。
- `npm run audit:diversity`：逐题记录完整数据并独立复验；拒绝、超预算和超过8秒单列。

本轮审计见 `fresh-diversity-audit-v4.txt` 及 `docs/diversity-audit/v4-audit-30.json`。旧 `fresh-diversity-audit.json` 是上一版22模式历史报告，不是本版结果。DOM和Worker测试不是浏览器像素检查或用户Windows/手机实机验收。
